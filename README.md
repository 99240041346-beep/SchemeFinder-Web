# SchemeFinder

Premium citizen welfare scheme discovery and eligibility guidance platform.

## Run locally
python app.py

The app serves on http://localhost:8000.

## Main features
- Citizen profile and editable eligibility profile
- Explainable scheme matching
- Smart document readiness
- Scheme comparison and explorer
- Natural-language profile extraction
- Browser voice input
- English, Telugu, Tamil, Hindi, Kannada and Malayalam UI
- Responsive civic-tech dashboard
- 3D login experience with optional Google Sign-In
- Official-source links and informational-match disclaimer

## Google Sign-In
Set the Google OAuth Web Client ID in **Settings → Google connection**. The browser uses Google Identity Services. Configure the deployed site origin in Google Auth Platform as an authorized JavaScript origin.

## Disclaimer
SchemeFinder provides informational matching against its indexed scheme data. A match does not guarantee entitlement. Always verify current eligibility, documents, deadlines and application instructions with the official authority.
